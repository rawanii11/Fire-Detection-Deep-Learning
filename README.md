# Fire Detection Using Deep Learning

## Project Overview

This project implements a binary image classification system to detect fire and non-fire images using deep learning techniques.

## Dataset

Kaggle Fire Dataset:
https://www.kaggle.com/datasets/phylake1337/fire-dataset

## Models Implemented

1. Custom Convolutional Neural Network (CNN)
2. MobileNetV2 Transfer Learning Model

## Tools and Technologies

* Python
* TensorFlow
* Keras
* Google Colab
* NumPy
* Matplotlib
* Scikit-learn

## Methodology

* Dataset preprocessing and normalization
* Custom CNN architecture with Batch Normalization and Dropout
* Transfer Learning using MobileNetV2
* Model evaluation using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix

## Results

### Custom CNN

* Training Accuracy: 97.12%
* Validation Accuracy: 89.95%

### MobileNetV2

* Training Accuracy: 99.87%
* Validation Accuracy: 96.98%

## Conclusion

The MobileNetV2 transfer learning model outperformed the custom CNN model and achieved better generalization on the fire image classification task.
